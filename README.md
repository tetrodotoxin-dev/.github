# Tetrodotoxin organization profile

This repository owns the public profile for
[`tetrodotoxin-dev`](https://github.com/tetrodotoxin-dev). GitHub renders
[`profile/README.md`](profile/README.md) on the organization page.

The [website](https://tetrodotoxin.dev) introduces the project through Build,
Infrastructure and DSL entry points. The
[documentation](https://tetrodotoxin.dev/docs/) explains the shared contracts,
while the [Godot image lab](https://tetrodotoxin.dev/#godot-lab) demonstrates
independently supplied capabilities in one application.

The organization profile states the common project boundary and routes readers
to the repository that owns each capability. Detailed API contracts remain with
their public declarations, and build instructions remain with the repository
that validates them.
